# RNA-Seq Differential Gene Expression Analysis

## Overview
This project performs an end-to-end RNA-Seq differential expression analysis using **R** and **DESeq2**. The objective is to identify differentially expressed genes (DEGs) between biological conditions and visualize the results using Volcano Plots and Heatmaps.

## Repository Structure
```text
rna-seq-analysis/
├── data/          # Raw and preprocessed count matrices
├── scripts/       # R scripts for DESeq2 pipeline
└── results/       # Output figures (Volcano Plots, Heatmaps) and DEG tables
